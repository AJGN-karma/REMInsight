## Project Description

REMInsight is a cutting-edge project designed to delve into the dynamics of REM sleep for the diagnosis of psychiatric disorders. Our goal is to harness advanced machine learning techniques to analyze sleep patterns and provide insights that can lead to better understanding and treatment of mental health issues.

### Technologies Used

- **XGBoost:** For effective predictive modeling.
- **Next.js:** To build a responsive and dynamic web application.
- **FastAPI:** To create efficient APIs for our application.
- **Firebase:** For real-time data storage and synchronization.
